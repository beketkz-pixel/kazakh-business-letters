# kazakh-business-letters — делопроизводитель на казахском языке

Навык (skill) для Claude: пишет, оформляет и проверяет служебную переписку и внутренние документы на **казахском языке**
(кириллица) по Правилам документирования и управления документацией в Республике Казахстан (приказ № 236).

## Что умеет

| Режим | Пример запроса | Результат |
|---|---|---|
| Черновик → письмо | «Оформи и переведи: …» — русский текст в любом виде | официальное письмо на русском и казахском, файл `.docx` |
| Документ по заданию | «Напиши приказ о …», «переведи на казахский служебную записку» | документ на казахском (и русском), файл `.docx` |
| Проверка перевода | «Проверь перевод», «вычитай» — казахский текст, с оригиналом или без | отчёт о замечаниях и исправленный текст |

Навык срабатывает и на короткие вопросы: «как по-казахски в письме “в связи с вышеизложенным”?».

Внутри:
- инструкция с порядком работы, структурой писем, приказов, протоколов, актов, заявлений, справок, доверенностей
  и чек-листом самопроверки;
- справочники: клише RU–KZ, термины делопроизводства и законодательства, сокращения, грамматика и типичные ошибки
  перевода, актуальные названия органов и актов;
- скрипты на Python (только стандартная библиотека): `lookup.py` — поиск по справочникам, `kzcheck.py` — автопроверка
  казахского текста (44 шаблона и сверка чисел с русской версией).

## Установка в claude.ai

1. Скачайте `kazakh-business-letters.skill` из последнего релиза:
   [Releases](https://github.com/beketkz-pixel/kazakh-business-letters/releases/latest).
2. В claude.ai: **Настройки → Возможности**, включите выполнение кода, затем в разделе **Навыки** загрузите файл.
   При обновлении сначала удалите прежнюю версию навыка.
3. Проверьте в новом чате: «Переведи на казахский: В связи с проведением инвентаризации просим предоставить сведения
   до 15 октября».

## Источники

Нормативные правовые акты РК по официальным текстам ИПС «Әділет» (adilet.zan.kz), решения Республиканской
терминологической комиссии, учебные издания по казахскому делопроизводству и образцы документов портала resmihat.kz.
Названия органов и актов сверены по состоянию на сентябрь 2026 года.

## Ограничения

Навык помогает составить и проверить документ, но не заменяет ответственного исполнителя: реквизиты, названия органов
и ссылки на НПА перед отправкой проверьте по действующей редакции. Это не юридическая консультация.
